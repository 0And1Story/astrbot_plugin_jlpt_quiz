# JLPT 刷题

AstrBot 日语刷题插件，支持 N1–N5 **词汇、文法、阅读、听力**，可在私聊作答或群聊抢答。推荐 QQ／NapCat／OneBot v11，需 AstrBot ≥ 4.5.0。

> [!IMPORTANT]
> 默认题库包含 AI 生成题，题目、答案和解析可能不准确。AI 生成题默认未启用，可在插件设置中开启。

## 使用

在 AstrBot 插件管理中通过本仓库地址安装／更新，启用后即可使用。

| 命令 | 功能 |
| --- | --- |
| `/n1词汇`、`/n1ch` | 词汇题 |
| `/n1文法`、`/n1wf` | 文法题，含选择、排序和篇章文法 |
| `/n1阅读`、`/n1yd` | 阅读题 |
| `/n1听力`、`/n1tl` | 听力语音题 |
| `/n1综合` | 综合抽题 |
| `/jlpt抽题 文法` | 所有等级的文法题 |
| `/jlpt 文法排序 n1` | N1 文法排序题，题型名称见 `/jlpt题型` |
| `/jlpt抽题 n1 文法 AI` | 仅抽 AI 生成题（需在配置中开启） |
| `/jlpt抽题 文法 n2 真题` | 仅抽符合条件的历年真题 |
| `/jlpt`、`/jlpthelp` | 显示帮助 |
| `/jlpt题库` | 查看当前题量 |
| `/jlpt结束` | 取消本题 |

将 `n1` 换成 `n2`～`n5` 即可切换等级。直接回复选项数字或字母，无需 @机器人；**群聊首个有效答案即结算，答错也公布答案**。发送“查看答案”或“放弃作答”可提前公布答案，提前公布和取消限出题者或 AstrBot 管理员。

`/jlpt抽题` 后可按等级、大类、具体题型、`AI`／`非AI`、`真题` 筛选，条件用空格分隔，顺序不限，省略的条件不限制。例如 `/jlpt抽题 文法排序 n1` 与 `/jlpt n1 文法排序` 等效；单独发送 `/jlpt抽题` 则从当前启用的全部题目抽取。

同一会话同时进行一道题。长阅读在 OneBot v11 群聊中使用合并转发；图片题按原题编号回答。

## 设置

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| AI 生成题目 | 关闭 | 开启后可抽取 AI 生成题；`非AI` 仅指未标记 AI 生成，不保证人工编写 |
| 群聊词汇／文法超时 | 60 秒 | 超时公布答案和解析 |
| 群聊阅读超时 | 180 秒 | 按文章、题干和选项每分钟 300 字（不计空白）加 30 秒估算，与配置值取较大值；纯图片阅读沿用配置值 |
| 群聊听力超时 | 120 秒 | 有时长信息时，至少预留音频时长加 30 秒 |
| 私聊超时 | 0（不限时） | 启用计时后，同样适用阅读和听力的自动延长规则 |
| 阅读折叠阈值 | 300 字 | 范围 0～5000，0 表示总是折叠 |

## 题库

默认附带可分发的社区练习题，包含明确由 AI 生成或审核的内容，其余来源的生成方式未披露。来源、AI 参与情况和授权见 [题库说明](data/NOTICE.md)。自动清洗不等于人工审题，答案和解析仍可能有误。

程序支持 21 个细分题型，各等级实际题量以 `/jlpt题库` 为准。官方样题、额外听力和自定义题库的添加方式见 [添加题库](data/QUESTION_BANKS.md)；这些本地数据不会随 Git 上传或被更新覆盖。
